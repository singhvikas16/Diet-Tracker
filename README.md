# 🌱 Diet Tracker

A comprehensive diet plan tracker for Vikas and Supriya's weight loss journey from 93kg to 80kg.

## Features

### 🎯 **Personalized Dashboard**
- Custom meal plan integration
- Real-time calorie tracking (1800 daily target)
- Weight logging with progress visualization
- Daily streak counter and achievement badges

### 📊 **Progress Tracking**
- Interactive weight loss charts
- Weekly/monthly progress calendar
- Achievement system with milestone celebrations
- Progress photo tracking

### 🍽️ **Meal Library (24+ Options)**
- Personalized diet plan meals
- Detailed nutritional information
- Search and filter functionality
- Step-by-step cooking instructions

### 🎉 **Cheat Day Planner**
- Strategic treat planning with calorie budget
- 8 indulgent options
- Smart scheduling system
- Recovery tips and guidance

## Tech Stack

- **Frontend**: HTML5, CSS3 (Tailwind CSS), JavaScript (Vanilla)
- **Charts**: ECharts.js
- **Animations**: Anime.js
- **Typography**: Typed.js
- **Storage**: LocalStorage (offline-first)
- **Deployment**: Static site (GitHub Pages/Vercel)

## Getting Started

### **Local Development**
```bash
# Clone the repository
git clone https://github.com/yourusername/diet-tracker.git
cd diet-tracker

# Start local server
python -m http.server 8000

# Open in browser
# http://localhost:8000
```

### **Deployment Options**

#### **Option 1: Vercel (Recommended)**
1. Push code to GitHub
2. Connect GitHub repository to Vercel
3. Deploy automatically on push

#### **Option 2: GitHub Pages**
1. Push code to GitHub
2. Enable GitHub Pages in repository settings
3. Deploy from main branch

#### **Option 3: Netlify**
1. Drag and drop the folder to Netlify
2. Automatic deployment

## Usage
