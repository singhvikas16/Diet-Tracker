# Diet Plan Tracker - Design Style Guide

## Design Philosophy

### Color Palette
- **Primary Green**: #2D5A27 - Deep forest green for trust, health, and growth
- **Secondary Sage**: #8FBC8F - Calming sage green for secondary elements
- **Accent Orange**: #FF6B35 - Energetic orange for CTAs and progress indicators
- **Neutral Gray**: #F8F9FA - Clean background for content areas
- **Text Dark**: #2C3E50 - Dark blue-gray for excellent readability
- **Success Green**: #27AE60 - Bright green for achievements and positive feedback

### Typography
- **Display Font**: "Playfair Display" - Elegant serif for headings and hero text
- **Body Font**: "Inter" - Clean, modern sans-serif for all body text and UI elements
- **Accent Font**: "Poppins" - Friendly sans-serif for buttons and labels

### Visual Language
- **Clean Minimalism**: Plenty of white space with focused content areas
- **Organic Shapes**: Subtle rounded corners and soft shadows for approachability
- **Nature-Inspired**: Leaf patterns and natural textures as decorative elements
- **Data-Driven**: Clear charts and progress visualizations with consistent color coding

## Visual Effects & Styling

### Used Libraries
- **Anime.js**: Smooth micro-interactions and element transitions
- **ECharts.js**: Interactive progress charts and calorie tracking visualizations
- **Typed.js**: Dynamic text effects for motivational messages
- **Splide**: Smooth meal option carousels and image galleries
- **p5.js**: Subtle background particle effects representing health journey

### Animation Effects
- **Fade-in Reveals**: Content sections appear smoothly as user scrolls
- **Progress Animations**: Weight loss progress bars animate on page load
- **Meal Card Hover**: Subtle lift and glow effects on meal selection cards
- **Counter Animations**: Daily calorie counts animate when updated
- **Success Celebrations**: Confetti effect when weight loss milestones are reached

### Header Effect
- **Gradient Background**: Subtle green-to-sage gradient with animated particles
- **Floating Elements**: Light leaf shapes that drift across the header area
- **Breathing Animation**: Gentle pulsing effect on the main logo/title
- **Parallax Scrolling**: Header elements move at different speeds for depth

### Interactive Elements
- **Meal Selection Cards**: Hover effects with nutritional info overlay
- **Progress Rings**: Animated circular progress indicators for daily goals
- **Weight Input**: Satisfying number counter with smooth transitions
- **Achievement Badges**: Unlock animations with particle effects
- **Calendar Heatmap**: Color intensity shows adherence to diet plan

### Mobile Optimizations
- **Touch Feedback**: Immediate visual feedback on all interactive elements
- **Swipe Gestures**: Smooth meal browsing with momentum scrolling
- **Thumb-Friendly**: All buttons sized for easy one-handed use
- **Progressive Disclosure**: Complex information revealed in digestible chunks

### Background & Layout
- **Consistent Background**: Soft sage green (#F0F4F0) throughout all pages
- **Card-Based Design**: Content organized in clean, elevated cards
- **Grid System**: Responsive 12-column grid for perfect alignment
- **Breathing Room**: Generous padding and margins for comfortable reading

### Data Visualization Style
- **Monochromatic Charts**: Using variations of the primary green palette
- **Subtle Animations**: Charts build progressively to tell the weight loss story
- **Interactive Tooltips**: Hover states reveal detailed nutritional information
- **Progress Indicators**: Circular and linear progress bars with smooth animations

### Accessibility Considerations
- **High Contrast**: All text meets WCAG 4.5:1 contrast requirements
- **Focus States**: Clear keyboard navigation indicators
- **Screen Reader**: Proper ARIA labels for all interactive elements
- **Reduced Motion**: Respects user preferences for reduced motion
